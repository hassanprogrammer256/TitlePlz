## Brand & Style

The design system establishes a high-velocity, cinematic reconnaissance interface built for crowd-sourced visual intelligence. The visual language blends high-end telemetric monitoring tools with the atmosphere of an elite midnight screening room. It serves cinephiles, detectives of lost media, video editors, and competitive spotters who dissect micro-clips, blurry frames, and vague quotes to identify obscure cinema in real time.

The aesthetic fuses **Sci-Fi HUD Minimalism** with **Refined Technical Glassmorphism**. Layouts feel structural, modular, and instrumentation-grade, avoiding decorative clutter while delivering responsive visual feedback. Deep obsidian tones anchor the eye, while laser-precise electric cyan conduits guide immediate action and warm amber beacons celebrate community achievements and solver ranks.

## Colors

The palette is engineered specifically for prolonged, late-night visual interrogation sessions:

- **Canvas & Surface Architecture**:
  - `Base Canvas`: `#0a0d14` (Deep void slate, grounding the viewing experience).
  - `Surface Tier 1`: `#101522` (Card backings, inspector trays, dock navigation).
  - `Surface Tier 2`: `#182032` (Modals, popovers, active widget tiers).
  - `Surface Glass Highlight`: `rgba(31, 41, 61, 0.45)` with `12px` backdrop blur.

- **Primary Signals (Signal Cyan)**:
  - `Primary Bright`: `#00f2fe` (Interactive highlights, clip playback states, primary buttons, positive audio waveform visualizers).
  - `Primary Core`: `#00c6ff` (Hover transitions, active terminal tabs, targeted bounding boxes).

- **Secondary Signals (Kinetic Gold)**:
  - `Reputation Gold`: `#ffb300` (MovieKing leaderboards, verified correct match seals, high-bounty bounties, master level badges).

- **Technical Structural Trims**:
  - `Border Base`: `#1f293d` (Structural dividers, inactive frames).
  - `Border Active / Focus`: `#2d3b55` (Hover accents, elevated container contours).

- **Data Readouts**:
  - `Text Primary`: `#f1f5f9` (Maximum clarity for titles and timecodes).
  - `Text Muted`: `#64748b` (Metadata, codec tags, secondary system timestamps).

## Typography

The design system runs exclusively on `JetBrains Mono` to enforce rigorous information density and programmatic visual structure. Tabular figures are used universally for frame rates, match percentages, runtimes, and leader ranks.

- **Letter Spacing Rigor**: Large headlines use tight negative tracking (`-0.02em` to `-0.04em`) to condense monospace width, while micro labels and terminal telemetry adopt expanded tracking (`+0.08em` to `+0.12em`) with uppercase transforms for immediate scannability.
- **Hierarchical Balance**: High-contrast contrast levels guarantee visual priority. Headings demand immediate inspection, body text delivers crisp multi-line readability for scene breakdowns, and tags provide immediate telemetry (e.g., `[RESOLVED // 99.4% MATCH]`).

## Layout & Spacing

A disciplined 12-column dynamic grid system hosts tactical widgets, multi-angle video preview screens, and live chat telemetry feeds.

- **Breakpoints**:
  - `Mobile` (<768px): 4-column flow. Feeds convert to single-column streams with fixed bottom playback controls. Margin: `1rem` (`16px`), Gutter: `1rem` (`16px`).
  - `Tablet` (768px–1199px): 8-column layout. Split-view workspace pairing the query media item with real-time candidate answers. Margin: `2rem` (`32px`), Gutter: `1.5rem` (`24px`).
  - `Desktop` (≥1200px): 12-column layout. Triple-pane workstation: navigation dock (2 cols), inspection cockpit & media analysis (7 cols), MovieKing scoreboard & activity queue (3 cols). Margin: `3rem` (`48px`), Gutter: `2rem` (`32px`).

- **Vertical Cadence**: Spacing increments snap strictly to 4px and 8px units, reflecting terminal grid mechanics.

## Elevation & Depth

Visual hierarchy does not use soft skeuomorphic drop shadows. Instead, it relies on stacked translucent obsidian panels, interior chromatic edge highlights, and high-frequency neon blooms.

1. **Surface 0 (Deep Canvas)**: Solid `#0a0d14` background featuring a faint 32px CSS background coordinate grid pattern rendered at 4% opacity.
2. **Surface 1 (Base Panel)**: `#101522` at 85% opacity, backdrop blur of `12px`, framed by a single 1px hairline border of `#1f293d`.
3. **Surface 2 (Floating Cockpit / Inspector)**: `#182032` at 90% opacity, backdrop blur of `20px`, bordered by `#2d3b55` with an ambient glow inset: `inset 0 1px 0 0 rgba(0, 242, 254, 0.15)`.
4. **Surface Highlight / Active Focus**: Targeted cards and hover states trigger a targeted electric cyan drop-shadow: `0 0 24px rgba(0, 242, 254, 0.12), 0 0 1px #00f2fe`.
5. **Prestige / Leaderboard Elevation**: Top-ranked MovieKing widgets gain an energetic amber aura: `0 0 28px rgba(255, 179, 0, 0.15), inset 0 0 12px rgba(255, 179, 0, 0.05)`.

## Shapes

The geometric framework is calculated and exact. Primary structural containers use a concise 4px radius (`rounded-sm`), establishing a durable, hardware-inspired frame profile. 

Sleek pill badges (`rounded-full`) are reserved exclusively for contextual status indicators, confidence index scores (e.g., `[ 98% MATCH ]`), and user reputation tiers. This visual distinction instantly separates transient telemetry data from permanent screen architecture.

## Components

### Buttons
- **Primary Kinetic**: High-contrast block styling. Background `#00f2fe`, text `#0a0d14`, font weight 600. On hover: shifts to `#00c6ff` with a `0 0 16px rgba(0, 242, 254, 0.4)` glow.
- **Secondary HUD**: Ghost style. Background `rgba(16, 21, 34, 0.8)`, border `1px solid #1f293d`, text `#00f2fe`. On hover: border transitions to `#00c6ff`, background to `rgba(24, 32, 50, 0.9)`.
- **Prestige / Bounty Action**: Background `#ffb300`, text `#0a0d14`. Applied exclusively for unlocking bounties or awarding MovieKing verification points.

### Sleek Pill Badges
- Ultra-compact status chips with uppercase mono labels.
- **Scanning Badge**: Background `rgba(0, 242, 254, 0.1)`, border `1px solid rgba(0, 242, 254, 0.3)`, text `#00f2fe`, accompanied by a pulsating 6px glowing dot.
- **MovieKing Crown Badge**: Background `rgba(255, 179, 0, 0.12)`, border `1px solid rgba(255, 179, 0, 0.4)`, text `#ffb300`.

### Terminal-Inspired Navigation Tabs
- Segmented rectangular control bar styled like a diagnostic shell.
- Tabs display terminal prefixes (`01 // ACTIVE_FEED`, `02 // UNRESOLVED`, `03 // ARCHIVE`).
- Inactive tabs feature transparent backgrounds, `#64748b` text, and borderless states.
- Active tabs snap to `#182032` with a lower edge baseline highlight in `#00f2fe` (`2px solid`) and `#f1f5f9` text.

### Input Fields & Search Bars
- Background `#101522`, border `1px solid #1f293d`, text `#f1f5f9`, placeholder `#64748b`.
- Left-adorned with a command-line prompt symbol (`>_`).
- Focused state eliminates generic native rings, introducing a crisp `1px solid #00f2fe` outline accompanied by an interior cyan wash (`rgba(0, 242, 254, 0.03)`).

### Cards & Media Inspector Widgets
- Root structure: `Surface Tier 1` with a `1px` stroke of `#1f293d`.
- Card Headers contain mono metadata stamps (timestamp, submitter hash, and bounty value).
- Media viewports inside cards have an aspect ratio lock (16:9 or 2.39:1 anamorphic) with hairline crosshair markers overlaid in each corner.

### Checkboxes & Segmented Radio Toggles
- Custom squared matrix checkboxes (`rounded: 2px`).
- Inactive: `#101522` background with `#1f293d` perimeter.
- Checked: `#00f2fe` solid background with `#0a0d14` check icon, surrounded by an ambient cyan pulse.

### MovieKing Leaderboard & Role Widgets
- Profile cards displaying tier levels (`REEL_NOVICE` to `CELLULOID_GOD`).
- Solved-counter telemetry counters using tabular figures.
- Top solver rows highlighted with a left border accent (`3px solid #ffb300`) and subtle amber atmospheric backdrop gradients.
